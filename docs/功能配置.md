# 功能和内容配置

site.config.js仍为JSON兼容对象。features内的map、secondAuthor、metadata、fieldNotes、frames、further分别控制地区索引、第二作者、参数、照片手记、画框和下一程。true启用，false关闭；默认演示全部能力。AI应先问需求再设置，不强迫保留所有模块。

关闭地图会移除导航入口，直达journey.html仍给出作品入口。关闭第二作者会从浏览集合和选择器移除该作者，已有friend地址显示空作品。作者内部键仍为kai/friend，显示姓名自由修改。关闭参数只隐藏参数，不删除照片记录；没有参数或手记时收起无用的信息入口。关闭画框不应用偏好，默认暖黑。

fieldNotes是“照片ID→纯文本”。手记按照片切换收起，无文字则不显示。示例demo-03包含明确标记的示例文字。第一次替换示例照片时把fieldNotes清空或换成新ID。

further按作者保存[{place,next,coverPhotoId}]。目标需为同作者不同地区且封面属于目标。示例关系仅演示，真实网站应根据内容人工确定；无推荐可设为空对象。专题页不显示下一程。

categories[].portrait配置手机竖屏封面图片键，focus如“50% 50%”配置构图焦点。未设置竖图时使用横图；完整照片始终在看图器中保持比例。首页先请求当前封面，其他照片在切换时加载。每个journey也可配置portrait。默认四分类；更大结构调整由AI在确认后一起改渲染和验证。

contact.email配置公开邮箱，socialLabel/socialUrl配置社交名称和完整HTTPS地址。空值不显示；邮件点击唤起设备默认邮件程序，社交在新标签打开，是否能唤起手机App取决于平台。不要填密码或私密信息。

摄影网站运行仍为普通静态文件；Python是本地导入/检查工具，Node只用于测试，AI工具是使用者自己的环境，不随站点运行。
