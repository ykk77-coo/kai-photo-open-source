# 将模板换成自己的摄影网站

## 1. 先换名字

在 `site.config.js` 修改 `brand.name`、`brand.subtitle`、`brand.title` 和 `brand.description`。`brand.footer` 填摄影署名，`brand.homeNote` 是首页短句。Lumen 的示例图另有说明。`authors.kai.name` 是主摄影者显示名，`authors.friend.name` 是第二位摄影者。保留内部键以维护已有照片链接。

`about` 控制介绍页：标题、简介、个人照片和各段文字。`portrait` 与段落 `image` 填照片的 `image` 键，暂时没有可填空字符串。普通文字会作为文本显示，不需要编写 HTML。

## 2. 导入并检查照片

在项目目录运行 `python -m pip install -r requirements.txt`。建议每个地点一个文件夹。导入默认追加并按内容去重，支持 JPG/JPEG、PNG 及当前 Pillow 能读取的 WebP。遇到 HEIC/HEIF 时，先在电脑或相册里本地导出 JPEG 或 PNG 副本，再导入。

```sh
python tools/import_photos.py --input "../我的原图/某次旅行" --place "某次旅行" --province-code 510000 --theme "自然" --tag "山间片刻" --replace --dry-run
python tools/import_photos.py --input "../我的原图/某次旅行" --place "某次旅行" --province-code 510000 --theme "自然" --tag "山间片刻" --replace --yes
python tools/import_photos.py --input "../我的原图/城市街巷" --place "城市街巷" --province-code 310000 --theme "城市" --tag "街边日光"
```

第一条只预览替换计划。确认要把整份示例目录换成自己的作品后，再运行第二条。第三条追加下一组；平常继续加图也用这种写法。旧网页图仅在仍被引用时随导出打包。新作品标题先显示「待命名」，原始文件名留在原图文件夹。

主题值对应 `categories` 前三项的 `theme`。默认是 `自然`、`城市`、`日常`。需要改主题时，同时修改配置和对应照片记录。第四个首页分类固定进入旅程目录。

摄影者默认为 `kai`，导入另一位摄影者的照片加 `--author friend`。同作者、相同文件内容会去重。不要对已经生成的网页副本再次导入，原图目录也不能包含输出目录。

## 3. 整理作品清单

`content/photos.js` 每项是一张作品。常改字段：

```js
{
  "id": "照片稳定ID",
  "image": "图片键",
  "author": "kai",
  "place": "某次旅行",
  "region": "更具体的地点",
  "provinceCode": "510000",
  "title": "你写的照片名",
  "theme": "自然",
  "tags": ["山间片刻"],
  "time": "pending"
}
```

这是字段摘录，不要用它覆盖完整记录；保留工具生成的 `urls`、`width`、`height`、`renditionWidths`、`metadata`、`real` 和 `sample`。`id` 用于分享链接，换标题不需要改 ID；`image` 用于封面引用。

`region` 多于一个时，地区旅程按地点分章；否则按每张照片的**第一个标签**分章，避免同一张在旅程中重复出现。作品筛选仍支持全部标签。

未知日期保留 `time: "pending"`，不编造拍摄时间。导入生成的参数是原图 EXIF 的选取项；没有的信息不必补齐。SVG 示例保留 `sample: true`；自己的真实照片由导入工具设置为 `false`。

## 4. 更换封面与专题

第一次用自己的照片替换示例目录后，在 `site.config.js` 一起更新以下引用。

- `categories[].image` 与 `categories[].portrait` 填横、竖封面的 `image` 键。没有单独选手机封面时，将 `portrait` 设为空字符串。
- 将 `journeys` 的示例地点替换成自己的地点。每组可填 `en`、横幅 `cover`、手机 `portrait` 和手记 `intro`。同一组封面使用同地点、同作者的图片键。空值使用默认选图。
- `about.portrait` 和 `about.sections[].image` 填自己的图片键或空字符串。`map.covers` 的地区封面同样换成自己的图片键，或设为 `{}`。
- `essays` 用照片 `id` 编排专题，暂时无专题时设为 `[]`。
- `fieldNotes` 与 `further` 的照片引用都使用照片 `id`。暂时无手记或下一程时，将对应字段设为 `{}`。 [字段规则](功能配置.md)

专题例子：

```js
{
  "id": "my-first-essay",
  "author": "kai",
  "title": "自己的专题名",
  "en": "My First Essay",
  "coverPhotoId": "第一张照片的id",
  "photoIds": ["第一张照片的id", "另一地区照片的id"]
}
```

`photoIds` 是阅读顺序，支持任意正数张，不限八张；同一专题不能重复、缺少或混入另一作者的照片。专题页面按顺序组合排版，点开任意照片后仍按当前作者全部作品循环。

## 5. 地区与地图

省级代码必须是六位字符串，可在 `tools/map.py` 的地区列表中查到。一个省只有一个作者章节时直接跳转；多个地点或作者时，预览区列出入口供访客选择。没有照片的省份不跳转。

默认图形为原创地区索引示意。站点已有可公开的本地省界 GeoJSON 时，可用下面的命令接入。数据支持 Polygon 或 MultiPolygon，每个地区需提供六位 `adcode` 或 `code`。

~~~sh
python tools/map.py --input "自己的省界.geojson" --attribution "数据来源及许可说明" --source-url "https://example.com/source"
~~~

运行 `python tools/map.py` 可恢复默认示意图。

## 6. 检查与发布

换图后执行 `python tools/verify.py`。它检查当前内容、临时静态导出和产物链接。若提示旧地点或旧图片引用，检查首页、旅程、关于页、专题和下一程。浏览器里再分别检查桌面和手机的导航与看图。`npm test` 用于仓库维护者回归默认示例。

用 `python tools/build.py --output dist-portfolio` 生成新的导出目录。把导出目录内的文件按原样放到已有站点的摄影路径，然后从该路径检查浏览、返回和单图直达。浏览书签保存在当前浏览器。删除照片后，失效的继续观看入口会隐藏。

普通预览的照片地址为 `works.html?author=kai&photo=稳定ID`。准备公开时，导出可填写实际部署的 HTTPS 地址，包含站点子目录。

~~~sh
python tools/build.py --output dist-public --site-url https://example.com/photos/
~~~

导出含静态图文。指定公开地址后，还会生成站点地图与单图分享页。分享图取自网页照片，SVG 演示适合浏览，试图文卡片时请用自己的 JPG、PNG 或 WebP。卡片样式以各应用的公开链接实测为准。站点根目录发布会生成 `robots.txt`。放在子目录时，可把 `sitemap.xml` 的地址加入现有网站的根规则。 [Open Graph](https://ogp.me/)
