# 五课做出自己的摄影网站

新建一段聊天，把 [Skill 文件](../skills/ai-photography-site/SKILL.md)上传给 AI，或复制全文发送。接着发[开场提示词](../README.md#开场提示词)，在同一段对话继续下面的步骤。

## 第 1 课　挑照片

先挑 6 到 12 张样片。告诉 AI 题材、张数和横竖比例就能开始。确认愿意给当前工具看时，再提交挑过的副本。涉及可辨认的人、住址或精确拍摄地点时，可以先用描述或占位图。

> 请用几行告诉我，这个网站给谁看、访客进来先做什么、第一版放哪组照片、需要哪些页面。看不出日期、地点或故事时先留空。还缺哪项关键决定，再问我。

**做完看到**　例如「朋友扫看六张街拍，点一张看完整照片」，或「给亲友按年份翻相册，再从某一年找到完整一组」。

## 第 2 课　挑一种看照片的方式

给出两个喜欢的词，例如「暖纸、留白」。参考截图可选。

> 请找适合我这组照片和目标的真实参考，附原始链接和你实际看过的页面。支持多 Agent 时，让参考研究和选片分别给建议。只能聊天时，用我的截图或描述做构想。请比较几种不同的观看方式，说明第一眼是什么、照片怎么分组、手机怎么排。我可以挑选、混合或提出自己的方向。

**做完看到**　有明确取舍的提案。例如「开场逐张看，适合慢慢读」和「先看主题索引，方便直接找图」。你可以说「保留主题索引，但一进专题用逐张图文」或「我想用年份开场」。 [KAI 排版案例](制作方法.md)

## 第 3 课　打开第一版

> 按我选的方向，先做最能看出效果的一屏和一条浏览路径。保留【我已决定的结构和风格】，把【还没决定的细节】先做成可改的。能操作文件就给预览入口，只能聊天就给我可以保存和打开的完整文件。也请告诉我照片放哪、怎样换图。

**做完看到**　浏览器里有一版可以选图或换图的网页。

收到 HTML 代码时，复制代码内容，保存为 `index.html`，再双击打开。Windows 记事本另存时选「所有文件」和 UTF-8。macOS 文本编辑先切换为纯文本。打不开时检查文件名是否误成 `index.html.txt`。本地选图用于试排版，重新打开时再选。想长期展示时，让 AI 帮你配置项目中的图片路径。

## 第 4 课　拿你的照片试一遍

电脑上看一次，再缩窄窗口。点开照片、关闭、返回。把一个具体问题告诉 AI。给重要照片写一句简短的替代文本，描述访客看不到图片时需要知道的画面信息。逐张核对来源、署名和公开范围。

> 请检查标题是否挡住主体、照片是否保持比例、手机有无横向滚动，以及看图后能否返回。先修我看到的【问题】，例如「手机标题盖住人脸」。告诉我改完去哪里复查。

**做完看到**　按你选的路径能找到并看清作品。可以先调留白和标题，也可以重新决定照片顺序或入口结构。满意后再用这套排法加更多照片。

## 第 5 课　接入已有网站

已有站点时，给 AI 工程目录或当前页面，并说明摄影页放在哪里。只做本地作品集，可以保存第 4 课的版本。

> 请把已确认的摄影页接入【例如 /photos/】。沿用现有框架和网址，告诉我文件放哪里。预览时检查导航、图片和单图直达。公开范围和发布目标由我确认。

**做完看到**　从已有站点能打开摄影页和照片链接。 [Lumen 换图与导出](使用指南.md)

## 在编程助手中加载 Skill

下载或克隆仓库，把完整的 [`ai-photography-site/`](../skills/ai-photography-site) 目录复制到要制作网站的项目内。从零开始可以先建一个空的项目文件夹。

| 工具 | 项目内最终路径 | 在项目中打开后 |
| --- | --- | --- |
| Codex | `.agents/skills/ai-photography-site/SKILL.md` | 输入 `$ai-photography-site`，再发开场提示词。 [官方说明](https://learn.chatgpt.com/docs/build-skills) |
| Claude Code | `.claude/skills/ai-photography-site/SKILL.md` | 输入 `/ai-photography-site`，再发开场提示词。 [官方说明](https://code.claude.com/docs/en/skills) |

新会话里也可以直接请编程助手读取项目中的 `SKILL.md`。联网、文件操作和多 Agent 取决于当前会话开放的能力。可以用[情景测试](../skills/ai-photography-site/evals/scenarios.md)检查 AI 的产出。
