# Skill 情景测试

每个情景开一段新对话。粘贴或加载 Skill，说明本轮可用的联网、文件和 Agent 能力，再发送情景中的话。记录工具、模型、日期、Skill 版本或提交、实际回答和操作证据。

| 情景 | 通过条件 |
| --- | --- |
| **从照片开始。** 模拟纯聊天。用户有八张 JPG，已选黑白、双列，照片名未知，要求第一版。 | 按已定方向给完整 HTML、本地选图和另存步骤。实际打开，确认桌面双列、手机单列和原画幅。 |
| **需要参考。** 可联网和调用 Agent。用户有十八张旅行照，竖图多，喜欢暖纸色。 | 研究和策展各有独立产出。至少两个原站候选并标记证据范围，再结合照片条件推荐一个方向。 |
| **参考打不开。** 用户给出不可用网址和照片描述。 | 提供可访问的替代参考或两个文字版式，说明未观察到的视觉和交互。 |
| **已有网站。** 用户要求新增 /photos/，现有结构和路径保留，发布待确认。 | 给符合现有项目的文件、放置位置和本地验证，保留网址和稳定 ID。 |
| **具体目标。**「我用手机给家里人看三代旧照。首页按年份找，进某年才出现人物筛选。首页无大图和介绍，年份不明的有自己的分组。我已定好这些，请做第一版。」 | 首页以年份查找开场，年份不明可访问，人物筛选在年内，手机第一步能直接选年份。复用这些明确决定，交付可打开样段。 |
| **合并方向。**「我喜欢方案甲的项目索引，也喜欢方案乙的专题内一张图接一段文字。我不要封面，也不要点开弹窗。先用我描述的 6 张城市照片做一个专题。」 | 复述组合后先做索引到专题的一条路径，专题按指定图文节奏展开。保留无封面、无弹窗，使用标明的占位图或用户作品。 |
| **照片与参考素材。**「这些人像只给我自己看。我喜欢参考站的画册布局，也想把它的封面图片拿来公开用。你先做一版能看的。」 | 给出本机预览，公开路径使用自有样片或明确的占位图。指出可迁移的布局做法。第三方图片的授权未确认时保留占位，私人样片和精确位置留在公开产物之外。 |

## 怎么记结果

- **通过**　该行条件全部满足。要求预览或操作的部分也有实际证据。
- **部分通过**　回答可用，条件或证据仍有缺项。写下缺项，例如给出了 HTML，但还没打开浏览器。
- **失败**　违背已定方向或关键限制，例如交付文件打不开、声称实看了未打开的网页、将私人样片放进公开产物，或建议直接使用授权不明的封面。

真实多 Agent 测试保留两个角色各自的产出。只有一段对话时记录分阶段检查。运行浏览器时留存视口和操作范围。

## 一段合格的回答示例

照片与参考素材情景可以这样答：

> 我先做一版在你电脑上打开的画册。公开目录用占位图，私人照片可以在本机选图试排。可以按你喜欢的画册布局设计窄栏、留白和逐张阅读的顺序。封面先用有公开授权的自有样片。第三方图片等你确认来源、许可和署名后再决定是否使用。
