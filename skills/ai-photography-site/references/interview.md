# 分轮访谈与设计简报

主 Agent 在每一轮维护一份简报。把信息记成「已确定」「此轮待选」「可以稍后决定」，使用者只需要看到此轮能决定的内容。问题每轮一到三个，优先提具体选择，少用设计名词。效果要由照片与使用方式解释。

## 第 1 轮　理解摄影者和访客

**输入**　照片样片、文件夹概况或文字描述。初次先用一小组来比较版式，用户可以用示例边试边准备。区分想展示的主题、照片数量、横竖比例与愿意公开的署名信息。

**可问的问题**

- 「谁最常看这个网站，朋友、同好还是潜在客户？」
- 「打开后，你喜欢访客先停下来欣赏一张大图，还是先从一组图中挑？」
- 「你现在有哪些组照片？给个大致数量，横图、竖图哪种多？」

**输出**　一句访问目标和一份照片概况。例如「朋友从手机进入，看 6 张街拍精选，点开能看完整照片；手头 8 张，竖图居多」。如果用户已说过数量和偏好，先把它们写进简报。

## 第 2 轮　弄懂审美并比较参考

先问用户常用的审美词、喜欢的截图和不喜欢的做法。用户说「高级」「干净」时，把它展开成不同选择。例如「纸白底、少量文字、照片间距宽」或「暖黑底、整屏主图、入口收起来」。比较观看方式，例如一开始看到一张图还是一个索引。用照片顺序、入口位置和点开之后的行为说明差别。

用[参考勘察手册](research.md)补充针对性的真实参考。每张候选卡给一条亲眼观察、一个明显取舍和一个可迁移的动作。问用户「你更想要哪种浏览节奏？」「这两种首页，哪种更像在看你的照片？」问完可让用户自己组合、删减或补充。把采用的构图、导航或相册方式连同来源写进简报。用户也可以给出自己的草图或直接定方向。

## 第 3 轮　确认首版内容

| 需要做的决定 | 给新手的解释方式 |
| --- | --- |
| 首页主要入口 | 对照访客想做的事来定。按地点、年代、人物、题材查找，或由作者安排一条阅读路线 |
| 封面和作品比例 | 封面允许裁切时说清主体落点，点开原图保留完整比例 |
| 页面与功能 | 列出完成主要路径所需的页面。看看搜索、地图、滚动故事或联系方式能否解决具体需求 |
| 桌面和手机 | 用实际照片说清大图、双列、单列的区别。标记手机另选竖幅的照片 |
| 署名和可见范围 | 记录愿意公开的姓名、联系渠道、题注、地点和拍摄参数 |
| 交付位置 | 默认电脑本地预览。现有网站写下框架和目标路径。发布决定留到成品确认 |

**输出**　把页面、时间优先级、介入的交互、缺少的素材与验收条件放进一小段简报。对重要的取舍给一句理由就够。用户说「都听你的」时，收敛到与照片匹配的最简单路线，说明采用的默认，并继续做可取消或可替换的样段。

## 第 4 轮　用样段收敛细节

先做对网站最关键的一屏和一条路径，尽量用同一组图比较。让用户看实际预览；仅能聊天时交付可打开文件并告诉用户观察哪里。请用户从下面选择一两处优先修：

- 第一眼看到的主体是否正确。
- 标题和导航会不会干扰照片，手机上是否看清。
- 列表的间距、图的排序和返回位置是否符合预期。
- 点开后的比例、关闭、翻页是否有清楚的操作。

把意见改写成可检查的要求。比如「太拥挤」可确认是标题、首排照片或留白，再写成「390 像素下竖图居中，首屏只露出一张图和主入口」。用户确认样段后扩展其他页面。

## 可复制的简报格式

~~~text
使用者与读者：
摄影类别／张数／横竖比例：
访客最重要的一步：
参考来源与采用的设计做法：
必须保留／想尝试／明确不要／交给 AI 决定：
首页与首版页面：
桌面／手机／完整原图规则：
公开素材范围与署名：
已经确认：
本轮最多三个待决定项：
首版完成标准：
~~~

用户要求跳到制作时，保留已有偏好并明确合理假设。风格、信息架构或公开范围改变时，集中确认差异。样段的小调整按已经同意的方向做。
